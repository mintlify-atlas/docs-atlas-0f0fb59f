HellDots is a drop-in JavaScript widget that adds a comment overlay to any web app. Your team clicks anywhere on a page to leave a comment anchored to that element — HellDots captures a screenshot, the browser environment, and a DOM fingerprint so comments survive page changes and re-anchor themselves automatically. You own the data entirely: route it to your own backend through callbacks, or use the built-in `localStorage` mode to get started immediately.

## What HellDots does

When someone leaves a comment, HellDots records more than the text. It captures a JPEG screenshot of the page as they saw it, an environment snapshot (URL, viewport size, browser, OS), and a structural anchor — a CSS selector plus a DOM fingerprint — that lets the comment re-attach to its element even after the page changes.

<Steps>
  <Step title="Install">
    Add HellDots to your project with a single npm install — or load it from a CDN with no bundler required.
    ```bash
    npm install helldots
    ```
  </Step>
  <Step title="Initialize">
    Call `createCommentOverlay` once on the client. A toolbar appears at the bottom of the page.
    ```js
    import { createCommentOverlay } from "helldots";

    createCommentOverlay({
      user: { name: "Ana" },
      persistence: "localStorage",
    });
    ```
  </Step>
  <Step title="Comment">
    Press <kbd>Alt</kbd>+<kbd>C</kbd> (or <kbd>Option</kbd>+<kbd>C</kbd> on macOS) to enter comment mode, then click anywhere on the page. HellDots captures a screenshot and environment snapshot automatically.
  </Step>
  <Step title="Triage">
    From the inbox sidebar, classify comments by type (bug, suggestion, question, improvement), set priority, add tags, and move them through the open → in progress → resolved lifecycle.
  </Step>
</Steps>
